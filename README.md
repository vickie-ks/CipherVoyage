# Ember.js 

This repository is a front-end sample project demonstrating a blogging platform built entirely with Ember.js. It serves as a showcase of my front-end development skills and experience with the framework.

## Project Highlights
* **Front-end Architecture:** Built a scalable single-page application structure for content delivery.
* **Ember.js Framework:** Utilized custom routing, component design, and state management.
* **Pipeline Automation:** Configured automated pipelines for building and deploying the site.
